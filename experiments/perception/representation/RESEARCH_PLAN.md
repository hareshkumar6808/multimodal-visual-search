## Cost-sensitive objective

Do not assign an ungrounded numeric exchange rate between losing information and retaining extra pixels. Use a lexicographic objective:

1. Hard safety constraint: never use content-only predictions to authorize pixel deletion or suppress image forwarding. Current consumers do not take the representation field as an authorization; preserve that invariant.
2. Report critical classification errors separately: (a) true `pixels_required` predicted text/structure; (b) true `mixed` predicted text/structure; report counts and denominators.
3. Among policies that satisfy the safety constraint, prefer fewer unnecessary preserves and lower latency, while exposing the tradeoff rather than collapsing it into one score.
4. Treat model confidence as uncalibrated unless validation metrics support calibration. Unknown domains and query-specific demands are abstentions that retain pixels.

This objective reflects the asymmetric irreversibility of discarding visual evidence and avoids claiming that one extra inference millisecond has a known value relative to lost task information. Since the current pipeline does not discard image bytes based on this metadata, observed classifier critical errors are proxy classification failures, not observed production pixel deletions.

## Hypotheses and pre-registered experiment sequence

- **H1, already checked:** the two false pixel-discard classifier errors are image-heavy visual pages mislabeled as cheap text by the model; inspect proves both are visually salient. Test by recording image/source/annotation and confidence. Outcome: supported for these two examples only.
- **H2:** the actual Stage 1 `visual_required` disagreement gate rescues such errors on the current holdout. Test with the real OCR+perception call path and compare raw argmax, heuristic-only, and final selector outputs on identical examples. Does not test arbitrary/OOD sources.
- **H3:** max-softmax confidence thresholding alone is unsafe. Test validation-set critical errors and preservation coverage at thresholds; do not select thresholds on the historical test split. Note a high-confidence counterexample is already observed (0.9922).
- **H4:** no model/architecture change is defensible from this dataset because proxy labels, class imbalance, and domain mismatch dominate the evidence. Compare validation-only class-weighted checkpoint behavior with a same-configuration unweighted ablation if reproducible training is feasible; retain the original unless the validation and safety evidence justify a change. Do not use the already-consulted test set to choose a candidate.
- **H5:** existing data cannot establish query-conditioned representation sufficiency. Verify with real call signatures and downstream usage; document safe behavior cases separately from measured classifier metrics.

Planned order: (1) reproduce raw checkpoint baseline and inspect errors; (2) run same-example heuristic versus complete runtime selector, with exact counts; (3) validation-only calibration and threshold/preservation sweep; (4) one controlled training ablation only if it can be evaluated on validation without treating proxy metrics as truth; (5) deterministic scenario tests and integration-path review; (6) rerun full tests, Ruff, strict mypy and measurements. Historical test results will be marked exposed/diagnostic, not an untouched final evaluation.
